# Compose and Program Music in Python using EarSketch

## Overview
Compose and Program Music in Python using EarSketch is a Coursera guided project focused on creating digital music through Python programming. The project introduces music technology concepts by combining coding, audio sequencing, and sound design using the EarSketch platform.

## Features
- Compose digital music using Python
- Program beats, loops, and sound patterns
- Apply audio sequencing techniques
- Use EarSketch sound libraries and samples
- Learn creative coding through music production
- Generate customized music tracks programmatically

## Technologies Used
- Python
- EarSketch
- Audio Sequencing
- Music Programming
- Digital Audio Samples

## Project Workflow
1. Create a project in EarSketch
2. Import and use audio samples
3. Write Python scripts for music composition
4. Arrange beats and loops on multiple tracks
5. Apply transitions and timing controls
6. Generate and play the final music composition

## Key Concepts Learned
- Python programming basics
- Music sequencing and arrangement
- Audio manipulation techniques
- Beat pattern creation
- Creative coding concepts
- Digital music production workflow

## Installation & Usage
1. Create an account on EarSketch
2. Open the EarSketch code editor
3. Write and execute Python music scripts
4. Play and export generated compositions

## Example Code
```python
from earsketch import *

init()
setTempo(120)

fitMedia(YG_NEW_HIP_HOP_ARP_1, 1, 1, 5)
fitMedia(RD_ROCK_POPRHYTHM_MAINDRUMS_15, 2, 1, 5)

finish()
```
